Use cases

Why switch user agent?

  • Get the full site. Load desktop layouts and features that mobile pages hide.
  • Fix broken pages. Some sites only work properly in a specific browser.
  • Test your own site. See how it looks to Chrome, Firefox, Safari and iPhone visitors.
  • Avoid app nags. Some sites push a mobile app to Android visitors only.

How to change it

  • Open Settings → User agent.
  • Choose a preset from the list.
  • Reload the page.

FAQ

User agent: common questions

What is a user agent?

A short piece of text your browser sends to every website that says which browser, version and device it is. Sites use it to decide which version of a page to show you.

How do I change the user agent in Rapid+ Browser?

Open Settings → User agent and pick Default, Chrome (Desktop), Mozilla Firefox (Desktop), Safari (macOS), iPhone 6, iPhone 13 or iPhone 17. Reload the page for it to take effect.

What is the difference between the user agent and Desktop site?

Desktop site loads the full desktop version of a page using a desktop user agent and a wide viewport. The user-agent switcher lets you choose exactly which browser or device you appear as. Desktop site takes priority over a phone user agent such as iPhone.

Does changing the user agent make me anonymous?

No. It only changes one identifier. Websites can still recognise you by your IP address, cookies and other browser features. Use it for compatibility and testing, not as a privacy guarantee.

Can I set a different user agent per profile?

Yes. The choice is saved per profile.

Why would a site look different after switching?

Many sites serve different pages, or extra features, depending on the browser. For example, a site might offer a desktop layout to Chrome and a simple layout to an iPhone.
