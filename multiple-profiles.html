What you get

Separate logins

Sign in to two accounts of the same site by using two profiles. Cookies and site data are not shared between them.

Instant switching

Tap your avatar and pick a profile. Your tabs stay open and pages do not reload, so you land exactly where you left off.

Settings per profile

Each profile remembers its own proxy, user agent, search engine, theme, start page wallpaper and site permissions.

Passwords per profile

Saved passwords belong to the profile that saved them, so your work logins never show up in your personal profile.

Deleting a profile removes its tabs, history, passwords and site data from your phone.

FAQ

Profiles: common questions

Can I use two accounts on the same website at once on Android?

Yes. Create one profile per account. Each profile has its own cookies and site storage, so you can be signed in to different accounts of the same site by switching profiles. This is stronger separation than tabs in a single profile, which share logins.

Do my tabs reload when I switch profile?

No. Rapid+ keeps each profile’s tabs alive, so switching back returns you to the same page and scroll position without a reload.

What is kept separate in each profile?

Tabs, history, bookmarks, saved passwords, cookies and site data, site permissions, the proxy and user-agent settings, theme and the start page wallpaper.

Is there a limit to how many profiles I can create?

No fixed limit is set in the app. Each profile stores its own data, so very many profiles use more storage.

Are profiles the same as private tabs?

No. A profile is permanent: it keeps history, bookmarks and logins for that part of your life. A private tab forgets everything when you close it. You can use private tabs inside any profile.

Does profile separation work on every phone?

Full separation of logins and cookies needs a recent Android System WebView. On older versions Rapid+ still separates history, bookmarks, passwords and settings, but website logins may be shared, and the Profiles screen tells you when that applies. Updating Android System WebView in Google Play fixes it.
